# X15 — DHT organs in the Sanexio blog

Local implementation for review; no push or deployment.

## Scope

- All four DHT posts have explicit typed organ assignments. Idea and Health
  Graph: heart, kidney, liver; participation: heart, liver; workshop: all six.
- Six mobile GLBs total 3,694,284 bytes. Male HRA exemplars, left SPL Carotis,
  SPL-MANIX thyroid. Source bytes and hashes are preserved; no geometry edits.
- Existing Health Graph image and article prose remain; the workshop gets a
  short introduction to the six models. Each model has a persistent 2D poster
  next to its 3D view (stacked on small screens).
- Loader bootstrap only at first load. three.js, GLB and the needed decoder
  load only when visible and clicked or after 1.5 seconds plus idle scheduling.
  Leaving the viewport cancels a pending idle load. Reduced motion/save-data
  disables automatic loading; reduced motion also prevents auto rotation.
- Rotation pauses offscreen/in hidden tabs and on manual interaction. Explicit
  pause/reset buttons and keyboard controls are available. Failure retains
  the poster and offers a retry. No JavaScript leaves usable static images.
- Visible attribution, source records, model/poster JSON-LD and article OG
  images/alt text are present. All executable dependencies are local.

## Verification

X15b: `public/scripts/organ-camera.js` frames the loaded organ meshes, using
the world-space organ box and 65% projected box coverage on the limiting
viewport axis. HRA source index 0 is the organ; source index 1 is attachment
vasculature (see `pipeline/web_export.py`). GLTFLoader preserves these original
node names in `userData.name`. SPL framing explicitly selects thyroid gland,
or carotid communis/interna/externa plus IJV; cartilage and vertebrae do not
affect framing. Missing target meshes fail visibly instead of fitting all meshes.

The manifest's anterior axes remain authoritative: HRA +z, SPL -z, up +y.
No geometry transforms are introduced. Zoom spans 8% of initial distance to
at least four times that distance; full-scene bounds only extend zoom-out and
far clipping. Panning permits vessel inspection. Resize preserves orbit/pan
and relative zoom, and updates the anterior reset pose for the new aspect.
The framing mapping lives alongside the source camera in `src/data/anatomy.json`
and must be preserved/rechecked when refreshing model metadata.

`tests/anatomy-camera.mjs` checks all six shipped assets at three aspect ratios,
perspective projection, HRA/SPL anterior signs, transformed/multi-primitive
meshes, hidden targets, missing mappings, and independence from arbitrarily
long vessels/SPL context. HRA/thyroid are loaded with the real GLTFLoader and
Meshopt decoder; the Draco carotid test uses exported POSITION bounds, with
actual Draco decompression covered by the asset suite. Browser tests additionally
check that Home/reset restore the initial view after orbit and zoom.

```sh
npm run build
npm test
npm run check
```

`npm test` verifies hashes and actual decompression of every compressed buffer
and Draco mesh (163 primitives), generated HTML/JSON-LD, image preservation,
and loader state transitions including cancellation, preferences and errors.
Run after the build. No lint configuration existed in the original repository.

Browser acceptance is prepared separately:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs npm run test:browser
```

The test intercepts requests and serves `dist/` directly from disk; no listening
port or external service is required. Screenshots default to `/tmp/x15-browser`.
Browser and contexts are closed in `finally`. It tests six rendered models,
rotation/pause, reduced motion, keyboard input, mobile overflow, error/no-JS
fallback, metadata and local-only network requests.

**Outstanding:** this sandbox rejects Chromium Mach-port registration. The
browser test could not run, and visual WebGL/mobile acceptance must therefore
be performed by the reviewer before publication. Build and Node tests do not
replace that acceptance. Copied poster/OG assets were visually inspected in a
contact sheet; their source crops were left unchanged.
